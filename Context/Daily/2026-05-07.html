  • Header down navigation skips TBE on PRE/HRM/GTE. PRE lands on LPF, HRM lands on H1, and GTE lands on THR.

  • Gate RAT has been renamed visually to DEP. Internally it still uses the existing gate_ratio field, but the user-facing meaning is gate/expander closed depth in dB.
  • Gate depth model: 8 maps to about 32 dB closed reduction, 20 maps to about 80 dB closed reduction. This is intended to make the gate actually shut bleed down instead of acting like a weak ratio.
  • Gate full-band mode draws the full threshold/depth relationship as level rings. The bright red threshold ring is the main reference.
  • Gate frequency mode is off by default. FRQ, WDT, and BND remain inactive/dim until FRQ is pressed.
  • Pressing FRQ creates/selects Band 1 and activates frequency-band gate editing. Pressing FRQ again disables band mode and returns to the regular full-band gate display.
  • Pressing BND adds/selects the next independent band. Rotating BND switches among enabled bands.
  • Each gate band has independent FRQ, WDT, THR, DEP, ATK, RLS, and GAN values. Switching bands must hydrate that band's own values into the visible editor controls.
  • In frequency-band gate mode, the same gate visualization moves to the selected frequency window and width. The red closed area is constrained to that frequency band; the old dashed/funky frequency guide was removed.
