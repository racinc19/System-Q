Major Work Completed Today

  • Fixed output-device selection and UI output meter/subtitle so System Q uses the active Windows/WASAPI output instead of silently choosing the wrong device.
  • Added AUX return audio routing: channel sends feed AUX returns, AUX returns process their inserts, and returns are mixed back to the master bus.
  • Added default AUX effects: A1 = Reverb, A2 = Delay, and A3 = Modulation.
  • Added solo-follow-send behavior: when a source channel is soloed, only AUX returns receiving active sends from that soloed channel are included with the solo.
  • Removed duplicate channel-strip send knobs while viewing send levels; the send fader display now uses the freed space.
  • Split the editor lower controls: transport/playback controls are above the timeline, while edit/automation buttons are isolated below the timeline.

Reverb State

  • Reverb is now wet-dominant on AUX returns instead of mostly dry insert-style blending.
  • Reverb tails continue processing after send input stops, so the tail is no longer cut off between hits.
  • Added REV reverse reverb toggle to the reverb row.
  • Verified by render tests that max reverb time produces materially stronger late-tail energy than short time, and reverse mode changes the wet output.

Delay State

  • A2 Delay now has a first-class DLY editor stage with TIME, FDB, MIX, WID, DMP, and PNG.
  • Delay DSP now includes delay time, feedback, wet mix, stereo width, damping, and ping-pong behavior.
  • Verified by render test that ping-pong/width changes the rendered delay output.

Known Issue / First Check Tomorrow

  • Next session should make AUX insert selection default focus to the active inserted effect: A1 -> RVB, A2 -> DLY, A3 -> MOD.
  • Modulation currently has basic audible DSP and default routing but does not yet have a dedicated editor stage or polar visual like reverb/delay.
